# xk6-sql-driver-hdb

Database driver extension for [xk6-sql](https://github.com/grafana/xk6-sql) k6 extension to support SAP HANA database.

## Requirements

- Go **1.25** or newer (required by xk6-sql and k6 v2).
- k6 **v2** — this driver is built against [xk6-sql](https://github.com/grafana/xk6-sql) `v1.2.2`, which uses the `go.k6.io/k6/v2` module. It cannot be combined with a k6 v1 build.
- A working Go module proxy. Do **not** set `GOPROXY=direct`: one of k6's transitive dependencies (`github.com/Soontao/goHttpDigestClient`) is no longer available on GitHub and can only be fetched from a module proxy. Keep the default `GOPROXY=https://proxy.golang.org,direct`, or point `GOPROXY` at your own mirror.

## Installation

### Docker

Docker setup example to build xk6 with the SAP HANA driver:

```Dockerfile file=Dockerfile
# syntax=docker/dockerfile:1

### Step 1: Build the k6 executable with the required extensions
FROM grafana/xk6:latest AS build

# Change to your target architecture (eg. amd64 or arm64).
ARG TARGETOS=linux
ARG TARGETARCH=amd64
ENV GOOS=$TARGETOS
ENV GOARCH=$TARGETARCH

RUN xk6 build v2.2.0 \
    --with github.com/LeonAdato/xk6-output-statsd@latest \
    --with github.com/grafana/xk6-sql@v1.2.2 \
    --with github.com/bersanf/xk6-sql-driver-hdb@v1.0.0

### Step 2: Create the image to run k6 load tests (this is an example)
FROM public.ecr.aws/amazonlinux/amazonlinux:2023

# The base image has no unprivileged user, so create one.
RUN dnf install -y shadow-utils \
    && dnf clean all \
    && useradd --create-home --shell /sbin/nologin k6

# Copy the executable from the previous step.
COPY --from=build /xk6/k6 /usr/bin/k6

COPY --chmod=0755 your-entrypoint.sh /k6/your-entrypoint.sh

USER k6
WORKDIR /k6

# Set the entrypoint to your script, which invokes k6.
ENTRYPOINT ["/k6/your-entrypoint.sh"]
```

### Virtual Machine (Amazon EC2 example)

```bash file=k6-setup.sh
#!/usr/bin/env bash
set -euo pipefail

# Change to your target architecture (eg. amd64 or arm64).
export GOOS=linux
export GOARCH=arm64

sudo yum install golang tar -y

go env -w GOPROXY=https://proxy.golang.org,direct

## install xk6
go install go.k6.io/xk6/cmd/xk6@v1.4.12

## build the k6 executable with required extensions
env GOOS=$GOOS GOARCH=$GOARCH xk6 build v2.2.0 \
    --with github.com/grafana/xk6-sql@v1.2.2 \
    --with github.com/bersanf/xk6-sql-driver-hdb@v1.0.0

sudo mv ./k6 /usr/local/bin/k6
```

## Example

```JavaScript file=examples/example.js
import sql from "k6/x/sql";
import driver from "k6/x/sql/driver/hdb";

//// for HANA 2.0
const db = sql.open(driver, "hdb://HANA_USER:HANA_PASSWORD@HANA_HOST:30015");

//// for HANA Cloud
//const db = sql.open(driver, ""hdb://<USER>:<PASSWORD>@something.hanacloud.ondemand.com:443?TLSServerName=something.hanacloud.ondemand.com");

export function setup() {
  db.exec(`
    CREATE COLUMN TABLE test_table (
      a INT GENERATED BY DEFAULT AS IDENTITY,
      b NVARCHAR(64),
      PRIMARY KEY (a)
    )
  `);
}

export function teardown() {
  db.exec("DROP TABLE test_table");
  db.close();
}

export default function () {
  let result = db.exec("INSERT INTO test_table (b) VALUES (?)", "One");
  console.log(`${result.rowsAffected()} rows inserted`);

  // SAP HANA uses positional '?' placeholders, not '$1', and folds unquoted
  // identifiers to upper case, so the result columns are named A and B.
  let rows = db.query("SELECT a, b FROM test_table WHERE b = ?", "One");
  for (const row of rows) {
    console.log(`key: ${row.A}, value: ${row.B}`);
  }
}
```

## Usage

Check the [xk6-sql documentation](https://github.com/grafana/xk6-sql) on how to use this database driver.

SAP HANA specifics worth knowing:

- **Connection string**: `hdb://<user>:<password>@<host>:<port>`, for example `hdb://myUser:myPassword@localhost:30015`. Extra options are passed as query parameters, eg. `?databaseName=myTenant`, `?timeout=60` or, for SAP HANA Cloud, `hdb://<user>:<password>@<host>:443?TLSServerName=<host>`. See the [go-hdb driver documentation](https://pkg.go.dev/github.com/SAP/go-hdb/driver) for the full list.
- **Query parameters** use positional `?` placeholders, not `$1`.
- **Column names** of unquoted identifiers are returned upper case (`row.A`, not `row.a`).
- **DDL** has no `IF NOT EXISTS`, and `TEXT`/unsized `VARCHAR` are not general-purpose column types — use `NVARCHAR(n)`.

## Development

```bash
make test   # runs the unit and (optional) integration tests
make build  # builds a k6 binary with this driver
```

The integration test needs a reachable SAP HANA instance and is skipped unless
the connection string is provided:

```bash
K6_SQL_HDB_DSN='hdb://myUser:myPassword@localhost:30015' make test
```
