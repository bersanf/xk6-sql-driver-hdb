🎉 xk6-sql-driver-hdb `v0.1.0` is here!

This release moves the driver to k6 `v2` and the current [xk6-sql](https://github.com/grafana/xk6-sql) extension.

Changes:

- Built for [xk6-sql](https://github.com/grafana/xk6-sql) `v1.2.2`, which uses the `go.k6.io/k6/v2` module (k6 `v2`). Extensions built against k6 `v1` are not compatible.
- Updated [go-hdb](https://github.com/SAP/go-hdb) to `v1.17.6`.
- Minimum Go version is now `1.25`.
- Fixed the query examples to use SAP HANA positional `?` placeholders instead of `$1`.
- The integration test now runs against a real SAP HANA instance when `K6_SQL_HDB_DSN` is set, and is skipped otherwise.

Build:

```bash
xk6 build v2.2.0 \
    --with github.com/grafana/xk6-sql@latest \
    --with github.com/bersanf/xk6-sql-driver-hdb@latest
```
